💡 Algorithmic Insights:
• BFS computes uniform hops, finding the shortest unweighted path but exploring an unguided circular frontier.
• Dijkstra minimizes weighted traversal costs using a priority queue.
• A* incorporates the admissible Manhattan distance heuristic ($h(n) = (|x_1 - x_2| + |y_1 - y_2|) \times C_{\min}$), focusing the frontier toward the destination and dramatically reducing nodes visited.
